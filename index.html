1系統架構總覽

先看懂「東西放在哪裡」，後面每一步就不會迷路。

四個名詞

  • OpenCode：裝在終端機裡的 AI 助理，負責聽你的指令、呼叫模型、處理檔案。
  • 本地推理引擎（Ollama / LM Studio / vLLM）：把模型實際跑在你電腦上的伺服器，預設位址是 127.0.0.1（本機）。
  • Flint40B（第一模型）：主力模型，用於生成學習單、解釋概念、撰寫教材等需要理解力的任務。
  • Beam（第二模型）：快速模型，用於檢查錯別字、核對答案、簡短摘要等輕量任務。

一句話講完資料流向

你在 OpenCode 輸入文字 → 傳到本機的推理引擎 → Flint40B 或 Beam 生成回答 → 回到你的終端機畫面。

整條路徑都在同一台電腦的迴圈位址（127.0.0.1）上完成，不會把資料送到雲端。

💡 為什麼要兩個模型？ 大模型（Flint40B）理解力好但較慢，小模型（Beam）速度快但較容易出錯。把「生成」與「檢查」分給不同模型，既能節省時間，也能讓第二個模型交叉檢查第一個模型的輸出，減少錯誤。

3安裝 OpenCode

挑一種你方便的方式安裝即可，裝好一種就夠。

方式 A：macOS（Homebrew）

brew install anomalyco/tap/opencode-v2

方式 B：macOS / Linux（一鍵腳本）

curl -fsSL https://opencode.ai/v2/install | bash

方式 C：npm（macOS / Linux / Windows，需 Node.js 18 以上）

npm install -g @opencode/cli

方式 D：Windows 獨立執行檔

  1. 從官方下載頁取得 windows-x64.zip（或 ARM64 版）。
  2. 解壓縮到例如 C:\opencode。
  3. 把該資料夾加入使用者 PATH（PowerShell，重開終端機生效）：
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\opencode", "User")

※ Windows 不支援 winget/scoop 等套件管理器安裝方式，請用獨立執行檔或 npm。

驗證安裝

$ opencode --version
opencode 2.x.x
  • 有顯示版本號 → 安裝成功，繼續下一章
  • 顯示 command not found → 重開一次終端機；仍不行則回頭確認安裝方式與 PATH（見第 11 章）

4安裝推理引擎與兩個模型

本教材以 Ollama 為例（最省事）。若您使用 LM Studio 或 vLLM，做法見本章末的替代方案。

4.1 安裝 Ollama

macOS

  • 從 Ollama 官網下載 .dmg 安裝，或：
  • brew install --cask ollama
  • 安裝後啟動 Ollama 應用程式（選單列會出現羊駝圖示）

Linux

curl -fsSL https://ollama.com/install.sh | sh

安裝完成會自動註冊服務；也可手動執行 ollama serve。

Windows：安裝官方 Windows 版後，Ollama 會常駐在系統匣。

4.2 確認引擎有在運作

$ curl http://127.0.0.1:11434/api/tags
{"models":[{"name":"...", ...}]}

只要不是「連線被拒絕」就代表引擎正常。若被拒絕，先執行 ollama serve（macOS 則確認 Ollama 應用程式已開啟）。

4.3 下載兩個模型

$ ollama pull flint40b
pulling manifest… 下載中（40B 級模型可能 20 GB 以上，請耐心等待）

$ ollama pull beam
pulling manifest… 下載中
⚠ 模型 ID 以清單為準 執行 ollama list 查看實際名稱。若清單顯示的是 flint40b:latest、Flint40B 或其他寫法，請一律以清單字串為準，後續 opencode.jsonc 與 /models 選擇時都要用同一個字串。

如果拿到的是 GGUF 檔（離線教材常見）

  1. 在模型檔所在資料夾建立文字檔 Modelfile，內容一行：
FROM ./flint40b-Q4_K_M.gguf
  1. 註冊進 Ollama（名稱可自取，建議就叫 flint40b）：
$ ollama create flint40b -f Modelfile
success
$ ollama list
NAME            ID              SIZE
flint40b        xxxxxxxx        22 GB
beam            xxxxxxxx        5 GB

4.4 各別測試一次

$ ollama run flint40b
> 請用繁體中文、以四年級學生能懂的方式，說明月相是怎麼來的（100 字以內）
月亮自己不會發光，它反射太陽的光。地球、月亮、太陽的位置不斷改變，
我們從地球看到被照亮的部分，形狀就不一樣，這就是月相……
> /bye

看到中文回答即成功。輸入 /bye 離開測試介面。

5設定 OpenCode（opencode.jsonc）

設定檔告訴 OpenCode：預設用哪個模型、去哪裡連引擎、第二個模型怎麼呼叫。

5.1 建立設定檔

在專案資料夾（例如 ~/moon-class）裡建立 opencode.jsonc：

📁 ~/moon-class/opencode.jsonc

{
  "$schema": "https://opencode.ai/config.json",

  // 第一模型（主力）：預設就用它
  "model": "ollama/flint40b",

  // 離線環境關閉更新檢查
  "update": "disable",

  "providers": {
    "ollama": {
      "settings": {
        "baseURL": "http://127.0.0.1:11434/v1"
      }
    }
  },

  // 第二模型（Beam）：註冊成子代理，隨時呼叫
  "agents": {
    "beam-assist": {
      "description": "使用 Beam 進行檢查、出題與摘要的子代理",
      "mode": "subagent",
      "model": "ollama/beam"
    }
  },

  // 給模型的長期規定（可選，但強烈建議）
  "instructions": ["teaching-rules.md"]
}

📁 ~/moon-class/teaching-rules.md

- 一律使用繁體中文（台灣用語）回覆，不要自動轉成簡體。
- 說話對象是國小四年級學生：句子要短、具體、少術語。
- 不確定的科學知識，請在句尾標註「請老師確認」。
- 出題時每題都要附答案與一句解釋。
💡 存檔即生效 OpenCode 會自動監測設定檔，存檔後不需要重開。若想強制重載，在 TUI 輸入 /reload。

5.2 模型 ID 怎麼寫

情境寫法
Ollama 自動探索到的模型ollama/flint40b、ollama/beam
清單顯示有 :latestollama/flint40b:latest（以清單為準）
模型在 LM Studiolmstudio/模型名
模型在自建 OpenAI 相容伺服器自訂 provider，見附錄 A-2
🔎 怎麼確認 ID 寫對了？ 啟動 OpenCode 後輸入 /models，清單裡找得到 ollama/flint40b 與 ollama/beam 就代表設定正確。找不到請見第 11 章「/models 看不到模型」。

6第一次跑通：驗證成功

五個步驟，看到中文回答就代表整套系統通了。

  1. 開啟終端機，進入專案資料夾

    cd ~/moon-class
ls

    應該看得到 opencode.jsonc 與 teaching-rules.md。

  2. 啟動 OpenCode（互動介面 TUI）

    $ opencode

    畫面會出現聊天輸入框與狀態列。

  3. 選擇第一模型

    > /models
（用方向鍵選取 ollama/flint40b，按 Enter）

  4. 送出第一句話

    > 請用繁體中文、以四年級能懂的方式說明月相是怎麼形成的，100 字以內。

  5. 看到中文回答 → 跑通了 🎉

    月亮本身不會發光，是反射太陽的光。太陽照亮月亮的一半，
但我們從地球看到「亮面」的角度每天不同，所以形狀會變化……

指令列一次指令模式（不進互動介面）

$ opencode run "請用繁體中文出 3 題四年級月相選擇題，附答案"
$ opencode run --model ollama/beam "檢查這句有沒有錯別字：月亮反射大陽的光"

第二條就是切換到第二模型 Beam 的最短寫法。

成功檢核

  • opencode --version 有版本號
  • ollama list 看得到 flint40b 與 beam
  • /models 清單裡有 ollama/flint40b 與 ollama/beam
  • TUI 中提問能得到繁體中文回答
  • opencode run --model ollama/beam "..." 也能得到回答
⚠ 常見卡關點 ① 忘記開 Ollama（引擎沒啟動）　② 模型 ID 大小寫或 :latest 與清單不一致　③ 設定檔 JSON 有全形逗號或漏括號（opencode.jsonc 支援註解，但基本語法仍要正確）。詳細排錯請看第 11 章。

7雙模型分工工作流（Flint40B ＋ Beam）

把兩個模型當成兩位老師：一位負責寫，一位負責檢查。

任務分配建議表

任務建議模型原因
生成學習單、考卷、長文解釋Flint40B40B 級理解力較好，長文較穩
錯別字檢查、標點與格式Beam任務單純，速度優先
核對選擇題答案Beam 初查 → Flint40B 複查雙模型交叉檢查，降低錯誤率

最終發布給學生／家長的內容老師人工審核本地模型仍可能出錯（幻覺）

① 互動介面切換（最直覺）

8.2 教學目標

  • 概念：能說出月球本身不發光，月相是「被太陽照亮的部分」在地球上看起來的形狀。
  • 技能：能連續 14 晚在固定時間、固定地點觀測，並正確畫出月相。
  • 態度：養成持續記錄、尊重觀測事實的科學態度。
  • 資訊素養（加碼）：能理解「AI 在本機運算」的概念，並知道 AI 輸出需要人工覆核。

8.7 觀測要領與安全

觀測要領

  • 固定：每天同一時間、同一地點，資料才可比較。
  • 定位：選一個固定參考物（如電線桿、窗框），記錄月亮在它的哪一側。
  • 先看再畫：先描述（亮面朝哪邊、多寬），再動筆塗黑。
  • 雲天也要記：寫上「雲多看不到」，這也是有效資料。
  • 不用望遠鏡也可以：雙筒望遠鏡可看亮面細節，但絕不可對著太陽。

安全提醒（務必宣導）

  • 夜間觀測由家長陪同，注意交通安全與地面高低。
  • 絕對不可直視太陽，也不可用望遠鏡對太陽。
  • 庭院、頂樓、窗邊都要注意防墜與照明。
  • 遇雷雨、颱風等惡劣天氣，改為室內討論或順延。

10離線使用與隱私

這套架構最大的價值：教室裡沒有網路也能用，學生資料不外流。

何時需要網路？

階段需要網路？說明
安裝 OpenCode、Ollama✅ 需要建議在有網路的環境先裝好
下載模型（ollama pull）✅ 需要40B 級模型可能 20 GB 以上，可先下載
日常對話、出題、檢查作業❌ 不需要全部在本機 127.0.0.1 完成
閱讀本教材（這個 HTML）❌ 不需要圖片全內嵌，離線完整顯示

離線環境的建議設定

{
  "$schema": "https://opencode.ai/config.json",
  "update": "disable",
  "model": "ollama/flint40b"
}

把 update 設為 disable 可關閉更新檢查，避免離線環境反覆嘗試連線。若只想在安裝時知道有更新，可改用 "notify"。

校園網路注意事項

  • 學校代理伺服器（proxy）可能擋住安裝腳本 → 先在家中或機房裝好，再把安裝檔與模型檔搬進校內。
  • 模型檔可直接複製：Ollama 的模型存放在本機資料目錄，整台電腦搬移時一併備份即可。
  • 建議在專案資料夾保留一份 opencode.jsonc 與 Modelfile，換機器時可快速重建。
💡 隱私三原則 ① 學生個資（姓名、成績、照片）不進提示詞。② 觀測紀錄用代號（學生 A、B）代替真名。③ 所有對話都在本機，不會離開這台電腦；但請仍遵守學校個資處理規範。

症狀可能原因處理方式

除錯常用指令

$ opencode service status
（檢查背景服務是否健康）

$ opencode service restart
（重啟背景服務；設定變更通常不需要這一步）

A-2 自建 / LM Studio 等 OpenAI 相容伺服器

當模型不是由 Ollama 提供時，自己宣告 provider 與模型（把 baseURL 換成你的位址）：

{
  "$schema": "https://opencode.ai/config.json",
  "model": "local/flint40b",
  "update": "disable",
  "providers": {
    "local": {
      "name": "本地伺服器",
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "http://127.0.0.1:1234/v1"
      },
      "models": {
        "flint40b": {
          "name": "Flint40B（第一模型）",
          "modelID": "flint40b",
          "limit": { "context": 32768, "output": 4096 }
        },
        "beam": {
          "name": "Beam（第二模型）",
          "modelID": "beam",
          "limit": { "context": 16384, "output": 2048 }
        }
      }
    }
  },
  "agents": {
    "beam-assist": {
      "description": "使用 Beam 進行檢查的子代理",
      "mode": "subagent",
      "model": "local/beam"
    }
  }
}

重點：models 的鍵名（flint40b、beam）才是 OpenCode 裡的模型 ID，modelID 才是送去伺服器的名稱。兩者不同時要分清楚。limit 請依模型實際 context 設定。
